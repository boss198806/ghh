# Telegram Bot with Numerology and OpenAI Integration

This Telegram bot calculates life path numbers and answers questions using OpenAI's GPT model.

## Setup

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/your-repo-name.git
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Set environment variables for your OpenAI API key and Telegram Bot token:
    ```bash
    export OPENAI_API_KEY=your_openai_api_key
    export TELEGRAM_BOT_TOKEN=your_telegram_bot_token
    ```

4. Run the bot:
    ```bash
    python bot.py
    ```

## Requirements

- Python 3.8+
- OpenAI API Key
- Telegram Bot Token (from BotFather)

## Features

- Life Path Number calculation based on user birthdate.
- Answer questions using OpenAI GPT-4 model.
